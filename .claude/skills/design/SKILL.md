# ckm:design Skill Overview

The `ckm:design` skill is a comprehensive design toolkit covering brand identity, design systems, UI styling, and multi-format content creation.

## Core Capabilities

**Logo Design:** Generates 55+ styles across 30 color palettes using Gemini AI, with industry-specific guides.

**Corporate Identity Programs (CIP):** Creates "50+ deliverables, 20 styles, 20 industries" including business cards, letterheads, and branded materials with mockups.

**Presentations:** Strategic HTML slides with Chart.js integration and copywriting formulas.

**Banner Design:** Supports "22 art direction styles" for social media, ads, web, and print across major platforms (Facebook, Twitter, LinkedIn, YouTube, Instagram, Pinterest, TikTok).

**Social Media Content:** Multi-platform image design with HTML/CSS export at exact pixel dimensions.

**Icon Design:** 15 SVG styles generated via Gemini 3.1 Pro in text format.

## Key Features

- Design token systems and CSS variables
- Tailwind + shadcn/ui integration
- HTML presentation rendering
- Screenshot export via Chrome DevTools
- Batch icon generation with multi-size support
- BM25 search for design assets

## Sub-skills Routing

External dependencies include `brand`, `design-system`, and `ui-styling`. Related skills: `frontend-design`, `ui-ux-pro-max`, `ai-multimodal`, `chrome-devtools`.

**Setup requires:** Gemini API key and Python packages (google-genai, pillow).
