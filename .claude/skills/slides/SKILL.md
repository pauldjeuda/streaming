# Slides

Strategic HTML presentation design with data visualization.

## When to Use

- Marketing presentations and pitch decks
- Data-driven slides with Chart.js
- Strategic slide design with layout patterns
- Copywriting-optimized presentation content

## Subcommands

| Subcommand | Description |
|------------|-------------|
| `create` | Create strategic presentation slides |

## Key Principles

- ALL slides MUST import `assets/design-tokens.css` — single source of truth
- Use CSS variables exclusively, never hardcoded values
- Duarte sparkline: alternate emotional states (frustration ↔ hope) at 1/3 and 2/3 deck positions
- Copywriting formulas: PAS, AIDA, FAB
- Chart.js for all data visualization
